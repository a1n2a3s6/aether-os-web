A sleek, browser-based **Desktop Operating System** built with zero build tools. Features a complete window manager, a persistent virtual filesystem shared across apps, a Unix-style Terminal, a Web Audio synthesizer with live oscilloscope, and a real-time System Monitor.

## Live Demo
👉 **[Boot AetherOS Live](https://a1n2a3s6.github.io/aether-os-web/)**

## Key Features
- **True Window Manager:** Drag, resize, minimize to dock, maximize/restore, and z-index focus stacking across multiple concurrent windows.
- **Persistent Virtual Filesystem:** Powered by `localStorage` and shared seamlessly between Terminal, File Explorer, and CodePad.
- **Unix-Style Terminal:** Supports `ls`, `cd`, `pwd`, `mkdir`, `touch`, `cat`, `rm`, `echo`, `neofetch`, `open`, and arrow-key command history.
- **CodePad Editor:** Edit virtual files with a live side-by-side Markdown preview.
- **SynthWave Studio:** Polyphonic Web Audio API synthesizer with keyboard playability, waveform switching, filter controls, and a real-time Canvas oscilloscope.
- **Live System Monitor:** Animated Canvas performance graphs and an active process list that lets you terminate open OS windows.

## Built With
- HTML5 & Canvas API
- Web Audio API
- Tailwind CSS (CDN)
- Vanilla JavaScript + `localStorage`
